## 22:55 🎉 MuJoCo 窗口终于显示成功 —— WSLg 坏掉，改用 VcXsrv :1

### 问题链（两个独立故障，都查透了）

**故障 1：WSLg 的 RDP 通道损坏**
- 现象：窗口进程存在但标题是 `msrdc: [WARN:COPY MODE] Shentoon RobotStudio`
- 根因（weston.log 实证）：
  `rdp_allocate_shared_memory: Failed to open "/mnt/shared_memory/{...}": Input/output error`
  → `RDP backend: enable_copy_warning_title = 1` → 图形通道降级成位图拷贝，渲染不出来
- 旁证：`Xwayland glamor: GBM Wayland interfaces not available`（GPU 加速也退化了）
- 处理：放弃 WSLg，改用 VcXsrv

**故障 2：VcXsrv 起不来的三个坑（逐个排掉）**
1. **显示号必须 `:1`** —— WSLg 占用 `:0`，抢 `:0` 会**静默绑定失败**（进程在但 0 个监听端口）
2. **参数必须分开传** —— 主人手打时出现 `-ac-nowgl` 粘连 → 报
   `Failed to activate virtual core keyboard: 2` + 访问控制没关
3. **缺 XKB 环境** → VcXsrv 调 xkbcomp 失败（`'"C:/.../xkbcomp"' is not recognized`）
   需设 `COMSPEC` / `XKB_CONFIG_ROOT` / `XKEYSYMDB` / `XLOCALEDIR`

**故障 3：WSL → Windows TCP 被拦**
- 已放行 Windows 防火墙（VcXsrv 规则 Private+Public、Port=Any）仍不通
- 真凶：**360 安全卫士的驱动级入站过滤**（`360secore.exe` 两条 Block 规则）
- 注意：360 的信任列表里要加**运行程序** `C:/Program Files\VcXsrv\vcxsrv.exe`，
  而不是安装包 `vcxsrv-64.21.1.16.1.install.exe`（主人一开始加错了）

### 成功配方（固化进 run_random5_autopilot.sh）

Windows 侧（管理员运行桌面 `start_x.bat`）：

set XLOCALEDIR=C:/Program Files\VcXsrv\locale
